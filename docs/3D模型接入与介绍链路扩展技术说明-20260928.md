## 1. 背景与结论

调研确认 ComfyUI v0.37 原生内置图生3D 节点（TRELLIS.2 / Pixal3D / Hunyuan3D 2.x / TripoSplat / MoGe / SAM3D-Body），官方模板「Pixal3D & TRELLIS.2: Image to Model」开箱即用。（另注：Civitai 上没有专门的 3D 底模，所谓"3D 特调"实为参考图 + SDXL 贴图工作流。）

## 3. 数据链路更新（本次的核心改动）

### 3.1 入库链路（未改代码，正常增量）

跑了上游的模型审计全链（scan→plan→hash→merge→civitai→civitai_red→hf→translate→extract→build），6 个新文件进入本地索引（327 条）。该审计工具链属于上游开发期工具，未包含在本仓库；开源版可用 `tools/collect_model_intros.py` 替代实现同样的采集目的。

**发现的链路缺口**：query_online.py 的 hf 反查对 Comfy-Org 单文件 repack 权重命中率低（只给到 `confidence: guess` 级的 repoId/tag，无 name/介绍）；且 build_app_intros.py 只消费 `info.civitai`，HF 来源模型永远显示"暂无介绍"。

### 3.2 DB 补录（数据操作，无脚本改动）

对 6 条 DB 记录的 `info` 字段手工补录为如下结构（`confidence: exact`，介绍文案取自 Comfy-Org 官方 repo 的调研信息）：

```json
{
  "source": "huggingface",
  "confidence": "exact",
  "hf": {
    "repoId": "Comfy-Org/Pixal3D",
    "name": "Pixal3D（int8 量化版）",
    "type": "图生3D 扩散模型",
    "author": "Comfy-Org（腾讯ARC 训练）",
    "baseModel": "Pixal3D 6.5B（TRELLIS.2 骨干）",
    "description": "……中文介绍……",
    "url": "https://huggingface.co/Comfy-Org/Pixal3D"
  }
}
```

### 3.3 build_app_intros.py 代码改动（三处，最小侵入）

文件：`F:\ComfyUI\comfychair\build_app_intros.py`

1. **hf 来源分支**（build_record 内，civitai 分支之后）：`if not civ.get("modelName") and hf.get("name")` 时从 `info.hf` 取 name/type/base/author/intro_original/url——Civitai 优先、HF 兜底，字段键与 civitai 分支完全对齐（App 端无需区分来源即可渲染）。
2. **PATH_KIND 白名单扩展**：新增 4 个目录映射 `/models/vae/`→vae、`/models/clip_vision/`→clip_vision、`/models/geometry_estimation/`→geometry_estimation、`/models/background_removal/`→background_removal。此前这些目录的模型完全不进 App 数据。
3. **KEEP_KINDS 中文名**：新增 vae→"VAE"、clip_vision→"图像编码器"、geometry_estimation→"几何估计"、background_removal→"背景去除"。

## 4. App 端需要感知的变化（版本迭代的输入）

1. **kind 枚举扩展**：数据里新增 4 种 kind——"VAE"、"图像编码器"、"几何估计"、"背景去除"。列表分组/图标/筛选若按 kind 白名单渲染需补齐，未知 kind 应有兜底显示。
2. **source 新值**：`source` 字段出现 `"huggingface"`（此前只有 civitai/unknown）。来源徽标/文案需覆盖。
3. **intro_original 的搭配建议**：6 个 3D 模型的介绍正文里包含配套模型说明（VAE/编码器/抠图模型），纯文本渲染即可，暂无结构化 companions 字段。
4. **"暂无介绍"条目变多**：白名单扩展使无介绍的存量条目进入数据，App 已有"暂无介绍"兜底，确认新条目下样式不破版即可。
